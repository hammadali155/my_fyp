# AI-Powered Classical Arabic & Quranic Learning Platform

Final Year Project — COMSATS University Islamabad, Attock Campus.

A learning platform that helps students study Classical Arabic (CA) and Quranic
linguistics with AI assistance: morphology (Sarf), syntax (Nahw), verse-based
drills, and spaced-repetition progress tracking, backed by NLP tooling
(CAMeL Tools, MADAMIRA, Farasa).

## Repo Layout

- `docs/` — proposal, defense deck, diagrams, and planning artifacts.
- `research/` — reference papers and literature review.
- Source directories (`backend/`, `frontend/`, etc.) will be added as the stack is chosen.

See `AGENTS.md` for working conventions and commands.
